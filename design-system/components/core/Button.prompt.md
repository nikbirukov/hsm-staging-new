The standard action button — green primary, navy secondary, outline for tertiary actions, danger for destructive ones.

```jsx
<Button variant="primary" size="lg" iconStart="bolt">Start free trial</Button>
<Button variant="outline" iconStart="picture_as_pdf">Export PDF</Button>
```

Sizes sm/md/lg map to 34/42/52px. `pill` only for marketing pages. One primary per view.
