Renders one Material Symbols Rounded glyph — the only icon primitive in this system; never hand-roll SVG icons.

```jsx
<Icon name="check_circle" size={20} fill={1} color="var(--pass-500)" />
```

Common names in product UI: `check_circle`, `cancel`, `warning`, `photo_camera`, `warehouse`, `forklift`, `assignment_turned_in`, `shelves`, `local_fire_department`, `picture_as_pdf`, `cloud_sync`.
