# UI kit — thehsmanager.co.uk (marketing site)

Recreation of the public marketing site: sticky translucent header, green-tinted hero, customer logo wall, problem cards, feature split, dark checklist section, testimonials, pricing, three-step onboarding and an FAQ accordion.

**Files**
- `index.html` — interactive page; the header switches between Home and Pricing.
- `SiteChrome.jsx` — `SiteHeader`, `SiteFooter`.
- `HomeSections.jsx` — `Hero`, `LogoWall`, `ProblemSection`, `FeatureSplit`, `ChecklistSection`, `Testimonials`, `StepsSection`, `FaqSection`, `Placeholder`.
- `PricingSection.jsx` — `PricingSection`, `PricingPage`.

**Source** Copy is taken verbatim from https://www.thehsmanager.co.uk/ (fetched August 2026). Photography and product screenshots from the live site were not supplied, so image areas render as labelled placeholders — swap in the real assets before using this for anything customer-facing.
